# «إنجاز» — نظام أعمال قسم الجاليات

نظام ويب يعمل بالكامل من المتصفح، لقسم الجاليات ورعاية المهتدين وطلبة البعوث في إدارة العلاقات الخارجية بوزارة الشؤون الإسلامية.

- **الموقع الحي:** https://injazkwt.com/
- **الواجهة:** صفحة واحدة (`index.html`)، تُبنى من المصدر في `src/` وتُنشر على GitHub Pages.
- **البيانات والدخول:** Supabase، وهو Postgres مع Auth وRLS وEdge Functions وRealtime.
- **الجسر:** إضافة Edge/Chrome في `bridge/`، تعرض Copilot وواتساب ويب داخل النظام.

## ماذا يغطي

- الأنشطة والجدولة: الأنشطة، والتقويم، والجدول الأسبوعي، و«هل الوقت متاح؟»، والوثائق (الموافقات)، وبوابة المنسقين، وحجز القاعات.
- الجاليات والمساجد: جالية لكل منسق، والمنسقون ونوابهم، والمساجد.
- العمل اليومي: المهام والإنجاز (لوحتي)، وإكمال البيانات، والطلبات الواردة مع رحلة كل طلب، ووثيقة، وتصاريح الدروس بباركود وتقارير الأئمة.
- التواصل: القرارات والتعاميم، وواتساب القسم داخل النظام، والمحادثات الداخلية، وتذكير التجديد.
- بوابة المنسقين (`portal.html`): حسابات بالرقم المدني بموافقة القسم، الطلبات والتعديل والإيقاف، رحلة الطلب، التقارير الشهرية، تسجيل الخطب والدروس، موضوع الجمعة بلغات الجاليات، والتنبيهات.
- خطب الجمعة: خطباء الجاليات، ومكافآت الخطباء وكشوف البنوك، وتسجيلات الخطب مترجمة ومقارنة بموضوع الجمعة المعتمد (Gemini)، وسجل التزام الخطباء.
- التقارير والسجلات: التقرير الشهري مع تقرير الخطب، والإحصائيات، والملاحظات، وخريطة الدروس.
- الإدارة: المستخدمون والصلاحيات، والنسخ الاحتياطية (يومية، وإلى OneDrive لكل مستخدم بحسابه)، وسجل التعديلات.

## البناء والنشر

```bash
cd src
python3 build.py          # يقرأ base/index.html ويطبّق modules/add*.js|css ثم يخرج index.html مضغوطاً
cp index.html ../index.html
# ارفع رقم الإصدار في ../sw.js (jaliyat-vN) حتى يتحدّث التطبيق عند الموظفين، ثم commit وpush
```

- يحتاج البناء إلى `python3` و`node` فقط.
- رسالة الـ commit تظهر للموظفين شارة «جديد».
- تفاصيل البنية في `docs/ARCHITECTURE.md`.
- قاعدة البيانات في `docs/DATABASE.md`.
- نسخ النظام لقسم أو إدارة أخرى في `docs/CLONE.md`.
